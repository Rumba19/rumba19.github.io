About

I'm a Senior .NET Engineer with a focus on enterprise backend systems, cloud-native AWS architecture, and — most recently — agentic AI. I've spent 6+ years building software that actually ships, stays maintainable, and handles real-world complexity.

At LAUSD I architected a large-scale student enrollment platform serving thousands of concurrent users — built on .NET Core, AWS SQS, Lambda, SES, and PostgreSQL. I owned everything from API design to security compliance to production deployment.

I'm currently building EnrollMate — an agentic AI system that autonomously processes enrollment applications using Semantic Kernel, AWS Bedrock, and .NET 10. It's my showcase for what enterprise software looks like when it thinks for itself.

I don't just write code — I'm involved in architecture decisions, code reviews, and technical direction. I care about systems that last, not just systems that work today.
